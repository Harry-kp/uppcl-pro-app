# Security policy

Please report security problems privately, not in a public issue: use GitHub's
[private vulnerability reporting](https://github.com/Harry-kp/uppcl-pro-app/security/advisories/new).

Especially interesting: anything that could leak a user's UPPCL credentials, session token or account
data off the phone, or let someone tamper with a payment. I'll reply within a few days.

UPPCL Pro is unofficial. Vulnerabilities in UPPCL's own systems should go to UPPCL, not here.
