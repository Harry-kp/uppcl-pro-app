# Code of conduct

Be kind and assume good faith. No harassment, insults or personal attacks, and never post anyone's
personal data (account numbers, phone numbers, addresses). Maintainers may edit or remove content and
block people who don't follow this. Report problems to the maintainer via a
[private advisory](https://github.com/Harry-kp/uppcl-pro-app/security/advisories/new) or GitHub profile contact.
